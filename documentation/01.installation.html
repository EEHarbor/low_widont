Low Widon’t

Low Widon’t keeps the final two words of a title or text together by replacing their separating whitespace with a nonbreaking space. Use it around the text you want to format.

Compatibility

Low Widon’t 4.1.1 uses the ExpressionEngine 3 and later add-on layout. The package metadata requires ExpressionEngine 3 or later; the release history records support through ExpressionEngine 7 and PHP 8.2. Choose a release appropriate for your installed ExpressionEngine and PHP versions. The older EE1 and EE2 versions are historical releases and are no longer under active development.

Installation

  1. Download and extract Low Widon’t.
  2. Copy the package’s low_widont folder to system/user/addons/, so that addon.setup.php is directly inside the installed low_widont folder.
  3. In the ExpressionEngine control panel, open Developer → Add-Ons, find Low Widon’t, and click Install.

These control-panel labels follow ExpressionEngine 7. Use your configured system directory if your site renames it. No separate theme files are supplied by this package.

Template Tags

{exp:low_widont}…{/exp:low_widont}: Wrap the text to format in this tag pair.

For example, format an entry title inside its Channel Entries loop:

{exp:channel:entries channel="news" limit="1"}
    <h1>{exp:low_widont}{title}{/exp:low_widont}</h1>
{/exp:channel:entries}

Replace news with your channel’s short name. The closing {/exp:low_widont} tag is required.

For the text Lorem ipsum dolor sit amet, the result contains a nonbreaking space between sit and amet. The output source uses the numeric HTML entity &#160;:

Lorem ipsum dolor sit&#160;amet

See the release notes for changes between package versions.
